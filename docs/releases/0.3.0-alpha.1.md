This alpha adds a standalone desktop app for Linux, macOS, and Windows alongside the Decky plugin and command-line updater.

- Browse connected devices and available firmware through a shared interface, with component illustrations and clearer controller/receiver identification.
- Install native desktop packages or standalone binaries with the Python backend included. No separate Python installation is needed.
- Check signed application updates on the Stable or Alpha channel. Review the version and release notes before applying an update. Desktop updates finish after the app closes and retain a backup for interrupted-update recovery.
- Use the same versioned backend API from the desktop app, Decky, or CLI. Application replacement is blocked while firmware workers are active, including workers using a custom state directory.

**Firmware support remains limited.** macOS and Windows support device discovery, firmware identity queries, and firmware browsing/preparation. Firmware installation and recovery are disabled on those operating systems until their write paths are validated. Linux retains the specifically reviewed receiver update and recovery paths; this release does not enable firmware installation for every 8BitDo model or wireless controller updates.

**The macOS and Windows installers are not OS-signed.** They have no Apple Developer ID/notarization or Windows Authenticode signature, so the operating system may warn about or block launching them. TUF signatures verify application-update content; they do not replace OS publisher signing.

This is a prerelease. Select **Alpha** to receive subsequent alpha application updates. Updating the app does not update any controller firmware or authorize a firmware write.
